# Random Number Generator

A simple React application built with Vite that generates a random number between 1 and 100 each time the user clicks the Generate button.

## Features

- Generates a random integer from 1 to 100
- Clean and modern user interface
- Responsive layout for desktop and mobile screens
- Fast frontend experience powered by React and Vite

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Installation

1. Open the project directory:

```bash
cd Generate-Random-Number
```

2. Install dependencies:

```bash
npm install
```

## Run the App

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Build for Production

```bash
npm run build
```

This creates a production-ready build in the `dist` folder.

## Usage

- Launch the app in the browser
- Click the Generate button
- A new random number appears on the screen
